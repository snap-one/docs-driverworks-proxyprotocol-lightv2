## ramp\_level

Configuration API indicating if the device brightness can be ramped to a level over a given time. Defaults to false.

When true, Composer programming offers the light's ramp commands, which take a ramp time in milliseconds (for example, **Ramp to Level** and **Ramp to Preset**). When false or omitted, those commands are not offered. The ramp request reaches the driver as [SET\_BRIGHTNESS\_TARGET][1] with a RATE.

This capability can also be changed at runtime with [DYNAMIC\_CAPABILITIES\_CHANGED][2].


### Signature

`<ramp_level></ramp_level>`


### Type

Boolean


### Dynamic Capability

Yes


### Example

```xml
<capabilities>
    <ramp_level>true</ramp_level>
</capabilities>
```
